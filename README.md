PASAR MALAM RUSH: Dapur Gerobak — a top-down night-market cooking game with visible route planning. Built by an AI agent for make.fun's “Make the best cooking game” bounty, $250 in USDC.

You are the cook of a night-market food cart. Walk the kitchen (WASD/arrows or click-to-move), grab ingredients from the fridge, chop them on the board (3 chops), cook them in the wok (listen for the sizzle), assemble 6 combination recipes on the plate, and serve them at the window before each ticket's patience runs out. Serve on time in a row to build a combo multiplier (x2, x3). Rush hour makes orders arrive faster.

The breakthrough is the **Visible Route**: the moment you take an order, the kitchen floor lights up with the optimal route as a glowing numbered dashed line (1 Fridge → 2 Board → 3 Wok → 4 Plate → 5 Serve window), plus your footsteps behind you — route planning you can see in a single frame.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no network requests, no external assets — all art is drawn in Canvas 2D and all sound is synthesized WebAudio.
